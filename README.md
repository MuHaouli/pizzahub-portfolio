# PizzaHub — Portfólio de Estágio

Site estático preparado para GitHub Pages. O arquivo index.html e todos os recursos ficam na raiz do repositório. Para publicar, selecione Settings → Pages → Deploy from a branch → main → / (root).

O site inclui instruções noindex para desencorajar a indexação em buscadores. Isso não limita o acesso: qualquer pessoa pode abrir o endereço, e um repositório público continua visível no GitHub.

Os documentos DOCX são cópias sem alterações dos arquivos enviados pelo aluno. O relatório PDF foi convertido a partir do original, sem edição de conteúdo.
