# PizzaHub — Portfólio de Estágio

Portfólio de Murilo Araujo El Haouli, matrícula 242041015, desenvolvido para o projeto de estágio em Ciência da Computação da UniFil, sob orientação de Renata Porto Gransoti.

## Ativar o site no GitHub Pages

Os arquivos já estão na branch `main`, na raiz do repositório. Para ativar a publicação:

1. Abra [Settings → Pages](https://github.com/MuHaouli/pizzahub-portfolio/settings/pages).
2. Em **Build and deployment**, selecione **Source → Deploy from a branch**.
3. Em **Branch**, selecione **main** e **/ (root)**.
4. Clique em **Save** e aguarde a primeira publicação terminar, normalmente em alguns minutos.
5. Volte a essa página e use o botão **Visit site** para confirmar o endereço publicado.

Após a ativação, o endereço esperado é: **https://muhaouli.github.io/pizzahub-portfolio/**.

O envio dos arquivos ao repositório foi concluído. A ativação do Pages requer uma ação do proprietário porque a integração não possui permissão para alterar a hospedagem.

## Baixar uma cópia

No repositório, clique em **Code → Download ZIP**, ou [baixe o ZIP diretamente](https://github.com/MuHaouli/pizzahub-portfolio/archive/refs/heads/main.zip).

Extraia o ZIP para guardar uma cópia no computador. Para visualizar os arquivos localmente, abra `index.html` no navegador. O vídeo do YouTube exige internet.

Para enviar a outro repositório, envie o conteúdo da pasta extraída, mantendo `index.html` na raiz e preservando as pastas `assets` e `documentos`. Depois configure o Pages como descrito acima. Não é necessário instalar Node.js, executar npm ou compilar o projeto.

## Organização dos arquivos

- `index.html`: todas as seções do portfólio.
- `styles.css`: aparência e adaptação a celulares.
- `app.js`: menu, filtros, ampliação das imagens e reprodução do vídeo.
- `assets/`: diagramas, telas e fontes utilizadas no site.
- `documentos/`: cópias dos DOCX originais, relatório convertido em PDF e pacote dos documentos.
- `documentos/originais.json`: hashes SHA-256 que permitem conferir a integridade dos documentos originais.
- `robots.txt` e as metatags de `index.html`: instruções para desencorajar a indexação em buscadores.
- `.nojekyll`: mantém o site como arquivos estáticos no GitHub Pages.

## Documentos e acesso

Os documentos DOCX são cópias sem alterações dos arquivos enviados pelo aluno. O relatório PDF foi convertido a partir do original, sem edição de conteúdo. As imagens foram extraídas do relatório.

Os arquivos foram preparados no ambiente de trabalho em nuvem da conversa, não no computador do aluno nem no Google Drive. Agora há uma cópia neste repositório. Baixar o ZIP salva outra cópia no dispositivo escolhido.

O site não utiliza links do Drive para entregar os documentos e não altera as permissões dos arquivos originais no Drive. As cópias deste repositório público podem ser visualizadas e baixadas por qualquer pessoa.

As instruções `noindex` desencorajam a indexação em buscadores; elas não criam uma senha nem limitam o acesso ao site ou ao repositório.
